# YT Watch Focus

git clone `https://github.com/Raviteja77/yt-watch-focus.git`

cd apps/web

run `npm i`

run `npm run dev`

cd services/api

run `npm i`

run `npm run start`

## Web

Created project using this command:`npx create-next-app@latest apps/web`

## Services
Created project using this command: `npx @nestjs/cli new services/api`
